# commons-profiles

Published visitor profiles for [Commons](https://vekbui96.github.io/commons/).

`profiles.json` is served by GitHub Pages at
https://vekbui96.github.io/commons-profiles/profiles.json and read by the public
Commons site at load time. It is written by the Publish button in the private
Commons Profiles tab (commons-api); don't edit it by hand unless publishing is down.

Profiles only choose which public apps a visitor sees. They are not access control:
everything here is public.
